Three steps: connect your account, add the overlay to OBS, and (if you want) let TradingView alerts place your trades. Everything runs on this computer.

1 Connect your MyFundedPerps account

  1. Open your API keys on MyFundedPerps. Pick Test (Sandbox) to practise first.
  2. Create a key: Read Only is enough for the overlay. Read And Trade is needed for TradingView trading.
  3. Paste it here. It's saved in the .env file on this computer only.

2 Add the overlay to OBS

  1. In OBS: Sources → + → Browser
  2. Paste this URL. Width 1920, height 1080.

3 Trade from TradingView Dry run

Your TradingView alerts place orders on your account. While Dry run is on, nothing is sent: you see what would be ordered. TradingView webhooks need a paid TradingView plan.

Closing a position is never blocked, so you can always get out.

ngrok (same address every time)

  1. Sign up free at ngrok.com, install it, and claim your free static domain.
  2. Run:
  3. Webhook URL in TradingView: https://YOUR-DOMAIN.ngrok-free.app/tv

Cloudflare (no account, new address each run)

  1. Windows: winget install Cloudflare.cloudflared · Linux: install the cloudflared package
  2. Run:
  3. Webhook URL: the https://….trycloudflare.com address it prints, plus /tv
