Install

It's a small app that runs on your computer. You need Node.js 22 or newer (free). About five minutes.

  1. Install Node.js: download the LTS installer from nodejs.org and click through it.
  2. Download Pass Live: Download ZIP then right-click the file → Extract All.
  3. Start it: open the extracted folder and double-click start.bat. A window opens and your browser goes to http://localhost:4747.
  4. Connect: on that page, paste your MyFundedPerps API key (step 1), then copy the OBS URL (step 2).
  5. OBS: Sources → + → Browser → paste the URL → width 1920, height 1080.

Trade from TradingView

Turn your TradingView alerts into orders on your MyFundedPerps account. The Setup page gives you everything to copy.

  1. Make a Read And Trade API key (try a Sandbox account first) and paste it into Pass Live.
  2. Open a tunnel so TradingView can reach your computer (see below).
  3. In TradingView, make an alert, tick Webhook URL, paste https://your-tunnel-address/tv, and paste the alert message from the Setup page.
  4. Watch it in Dry run. When it does what you expect, tick Send real orders and confirm.
  • Starts in dry run: nothing is sent until you say so
  • Secret passphrase on every alert
  • Max order value and max leverage
  • Pauses new trades when a limit is nearly used
  • Duplicate alerts never trade twice
  • Closing a position is never blocked

TradingView webhooks need a paid TradingView plan. You're responsible for the orders your alerts send.

The tunnel we use: localhost.run

No sign-up and nothing to install: Windows 10/11, Linux and macOS all have ssh built in. It's what we tested Pass Live with, and it worked on a network that blocks ngrok's sign-up and Cloudflare's quick tunnels.

  1. Start Pass Live, then in a second terminal run: 
    ssh -R 80:localhost:4748 nokey@localhost.run
    The first time, type yes when it asks about the host.
  2. It prints an address like https://63a6d153434ad2.app.lhr.life. Your webhook URL is that address plus /tv.
  3. Keep that terminal open. If you close it, or the free address rotates, put the new address into your TradingView alert.

Check it from any browser: https://your-address/tv should show a blank "not found" page. That answer comes from Pass Live, so the tunnel works.

Other tunnels

ngrok (an address that never changes, needs a free account): ngrok http --url=YOUR-DOMAIN.ngrok-free.app 4748

Cloudflare (no account): cloudflared tunnel --url http://localhost:4748. Some internet providers block these quick tunnels.

Troubleshooting

The problems we ran into while building and testing Pass Live, and what fixes them. Every alert shows its result under Recent alerts on the Setup page: start there.

Test without TradingView Premium

Send the same message TradingView would send, from a terminal. Use the passphrase from the Setup page and a new id each time.

Linux and macOS:

curl -X POST http://localhost:4748/tv -H 'Content-Type: application/json' -d '{"passphrase":"PASSPHRASE","action":"buy","symbol":"BTCUSDT","usd":500,"id":"test-1"}'

Windows (Command Prompt):

curl -X POST http://localhost:4748/tv -H "Content-Type: application/json" -d "{\"passphrase\":\"PASSPHRASE\",\"action\":\"buy\",\"symbol\":\"BTCUSDT\",\"usd\":500,\"id\":\"test-1\"}"

Close it with "action":"close", or every position with "action":"close_all".

Tunnel

Cloudflare says "failed to request quick Tunnel"

Your internet provider blocks Cloudflare's quick tunnels. Use localhost.run.

ngrok's sign-up page won't open

Some networks block it, on both phone and laptop. Use localhost.run: it needs no account.

Windows says 'ssh' is not recognized

Settings → System → Optional features → add OpenSSH Client, then open a new terminal.

Alerts stopped arriving

The tunnel terminal was closed, or the free localhost.run address changed. Start it again and paste the new address (plus /tv) into your alert.

Alerts

The reply says "ok":true but nothing traded

That reply only means "received". Look at "mode" in the reply and at Recent alerts. "Dry run" means real orders are off: tick Send real orders on the Setup page and confirm in the box that appears.

401 bad passphrase

The passphrase in the alert doesn't match. If you pressed New, copy the alert message from the Setup page again.

"Same alert already handled"

An alert with the same id already ran, so it won't trade twice. Use {{timenow}} in TradingView, or a new id when testing.

"No open BTC position to close"

There's nothing open for that symbol on the account in Trade on account. Check the account, or whether the buy was only a dry run.

"new trades are paused"

A guard: the daily loss or max drawdown is past the share you chose, or the account isn't active. Closing still works. You can change the share on the Setup page.

"Unknown symbol", "Give a size", "below the minimum", "over your max"

Fix the alert message: use a MyFundedPerps market such as BTCUSDT, add "usd" or "size", and keep the order between the market's minimum and your max order value.

Any other error

Recent alerts shows exactly what MyFundedPerps answered, including which field it refused. Open an issue with that line. Never include your API key or passphrase.

App

"Pass Live needs Node.js 22 or newer"

Install the LTS version from nodejs.org, then start Pass Live again.

"Port 4747 is busy"

Pass Live is already running in another window. Use that one, or close it and start again.

The key isn't accepted

Check it's copied whole and still active on MyFundedPerps. The overlay works with a Read Only key; trading needs Read And Trade.

Questions

Is my API key safe?

It's saved in a file on your computer and only ever sent to MyFundedPerps. OBS and your stream only get numbers. The app only answers to localhost, so websites can't reach it. The TradingView port accepts nothing without your passphrase.

Does it work with live accounts?

Yes. Sandbox keys start with fp_test_, live keys with fp_live_; Pass Live picks the right servers automatically.

Is it official?

No. It's an independent open-source tool built on the public MyFundedPerps API. It isn't made by or affiliated with MyFundedPerps.

What does it cost?

Nothing. It's MIT licensed. TradingView webhooks need a paid TradingView plan; the overlay doesn't.
